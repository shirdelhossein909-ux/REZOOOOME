The biggest challenge: a backtest that fooled us for three months

Our old backtest showed 825% profit, yet the live account was losing. Trade by trade, the robot's logic was right; the flaw was in the backtester: for an order filled inside a 4-hour candle, it assumed the candle's high and low came after the entry. It could see the future.

+77.6% → −51.2%two-year backtest, before and after fixing that one assumption
174 / 186syncs where the orders on the account matched the backtest exactly
26 → 31 / 33shared trades predicted correctly, before and after the fix
0.6%chance of the live result if the old backtest had been right

What we did: rebuilt the backtester on 1-minute data, and the robot and the backtester now share one decision engine. Today we are rebuilding the robot and re-running the backtests with this new engine.

Project 2: Mahak, a test bench for Persian support chatbots

first version builtnow testing on real chatbots

Mahak talks to a support chatbot the way a customer would, tests it on five levels and hands back a report card:

  1. Basics
  2. Persian as typed
  3. Multi-turn
  4. Honesty
  5. Attempts to trick it
  • Writes its questions from the company's own documents, and asks each one again with typos, colloquially and in Finglish.
  • A critical failure, such as leaking a password or a customer's details, zeroes that test; every check is compared with the previous one.
  • Tested on a real chatbot too: DeepSeek behind a one-line prompt scored 75 yet stayed below level 1, because it makes answers up; behind a careful prompt, 97. Mahak's judge agreed 98% with a model judge and 95% with my own labels.

Mahak's own AI support assistant

live on the Mahak site
What it doesA button on every page of the Mahak site opens it, and it answers visitors with the DeepSeek model, only from Mahak's own facts. It makes nothing up, takes no keys or passwords, and ignores hidden orders.
How I built itThe API key is never in the site but on a small server on Cloudflare. Each visitor has a message limit and a message costs about a tenth of a cent; if DeepSeek is slow, it asks again.
Tested with Mahak itselfFirst run 82 with a level ceiling of 3; after fixes 99, all 48 tests passed, ceiling 5. Mahak caught its real faults, such as no empathy for an angry customer; the first run's three critical failures were Mahak's own mistakes, now fixed.
